# Encrypt

## Overview:
An encryption method and usage done by me for fun in 12th grade when I learnt about .Dat files and pickling and thought of using it to encrypt files by pickling pickled data multiple times. Then implemented a TOR like system where 3 keys stored randomly in a folder or anywhere in the system or with different people are needed to open the file containing ciphertext. The cipher is a variation of the Vigenerre cipher and may not be very secure. However the implementation with multiple keys which are elsewhere on the same device prevents copying and opening in different computers by knowing the password. 
Further applications allow it to be a method to ensure consent of multiple owners of a file to open it.
